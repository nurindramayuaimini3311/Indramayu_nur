🛠️ Panduan Buat Aplikasi

ALWI PUSAT / Indramayu Nur — alur dari nol sampai publikasi. Urut dari atas, jangan lompat biar tidak konflik.

1️⃣ Persiapan Folder & File Dasar

  1. Buat folder baru di tempat yang sesuai: 
    NURgenerator/<nama-aplikasi>/     aplikasi baru di generator
offline/<nama-aplikasi>/          versi offline
fiturBARU/<nama-aplikasi>/        fitur eksperimen
  2. Minimal wajib ada: 
    index.html            (halaman utama)
manifest.json         (nama, icon, theme-color)
sw.js                 (service worker - cache offline)
img/icon-192.png      DAN img/icon-512.png
    Bikin icon dari ffmpeg: ffmpeg -i icon-512.png -vf scale=192:192 img/icon-192.png
  3. Patuhi aturan STATIC — jangan simpan node_modules/, tanpa backend. Kalau perlu server → pakai VM, bukan folder github.

2️⃣ Tambah PWA (biar bisa di-install)

Taruh di <head> index.html:

<meta name="theme-color" content="#38bdf8">
<link rel="manifest" href="manifest.json">
<link rel="icon" type="image/png" href="img/icon-192.png">
<link rel="apple-touch-icon" href="img/icon-192.png">

sw.js — cache network-first:

var CACHE='nama-aplikasi-v1';
self.addEventListener('install',function(e){self.skipWaiting()});
self.addEventListener('activate',function(e){e.waitUntil(clients.claim())});
self.addEventListener('fetch',function(e){
  e.respondWith(fetch(e.request).then(function(r){return r})
    .catch(function(){return caches.match(e.request)}));
});
⚠️ Scope SW ikut lokasi file. Kalau file ada di NURgenerator/aplikasi/sw.js, scope cuma NURgenerator/aplikasi/. Kalau mau mencakup seluruh portal, taruh sw.js di root + manifest scope = './'.

3️⃣ Publikasi ke GitHub

  1. Masuk folder repo: cd /root/ALWI_CENTER/Indramayu_nur
  2. Lepas folder dari .gitignore (kalau dilarang): 
    sed -i '/^NURgenerator\/$/d' .gitignore
    ⚠️ NURgenerator/node_modules/ TETAP di dalam ignore — jangan dihapus.
  3. Salin ke clone bersih + commit + push: 
    cp -r <folder> /tmp/opencode/github-sync/Indramayu_nur/
cd /tmp/opencode/github-sync/Indramayu_nur
git add .
git commit -m "Tambah aplikasi: <nama>"
git push origin main
