Deploy
------
Contoh perintah untuk deploy dari Termux / shell:

```bash
# Pastikan di folder projektu, mis. ~/hugoNUR8
cd ~/hugoNUR8
git add .
git commit -m "ALWI PUSAT FIXED - 185 file"
git push origin main

# Deploy ke Vercel (jika terpasang dan login)
vercel --prod --yes
```
