Penghapusan Data - ALWI META

Package: id.alwimeta.app
Pengembang: Indrmayuclub makrifat
Kontak: imahazzah51@gmail.com

ALWI META tidak mengumpulkan data pribadi atau akun. Semua data (skor & XP game) hanya tersimpan di localStorage perangkat Anda.

Cara Hapus Data

  1. Buka Pengaturan Android > Aplikasi > ALWI META.
  2. Ketuk Hapus Data / Clear Storage.
  3. Selesai — semua skor & XP game terhapus dari perangkat.

Atau uninstall aplikasi untuk menghapus semua data lokal.
