1. PERSIAPAN FOLDER & FILE DASAR
-----------------------------------------------------------------------------
1) Buat folder baru di tempat yang sesuai:
     <portal>/NURgenerator/<nama-aplikasi>/      aplikasi baru di generator
     <portal>/offline/<nama-aplikasi>/           versi offline

2) Minimal wajib ada:
     - index.html            (halaman utama)

     - sw.js                 (service worker - cache offline)
     - img/icon-192.png      DAN img/icon-512.png
                            (bikin dari ffmpeg, contoh:)
     ffmpeg -i icon-512.png -vf scale=192:192 img/icon-192.png

3) Patuhi aturan STATIC - jangan simpan node_modules/, tidak ada backend.
   Kalau perlu server -> pakai VM, bukan di folder github.


-----------------------------------------------------------------------------
2. TAMBAH PWA (BIAR BISA DI-INSTALL)
-----------------------------------------------------------------------------
Taruh di <head> index.html:

  <meta name="theme-color" content="#38bdf8">
  <link rel="manifest" href="manifest.json">
  <link rel="icon" type="image/png" href="img/icon-192.png">
  <link rel="apple-touch-icon" href="img/icon-192.png">

sw.js - cache network-first:

  var CACHE='nama-aplikasi-v1';
  self.addEventListener('install',function(e){self.skipWaiting()});
  self.addEventListener('activate',function(e){e.waitUntil(clients.claim())});
  self.addEventListener('fetch',function(e){
    e.respondWith(fetch(e.request).then(function(r){return r})
      .catch(function(){return caches.match(e.request)}));
  });

CATATAN:
- Scope SW ikut lokasi file. Kalau file ada di NURgenerator/aplikasi/sw.js,
  scope-nya cuma NURgenerator/aplikasi/, bukan seluruh portal.
- Kalau mau mencakup seluruh portal, taruh sw.js di root + manifest scope = './'.
