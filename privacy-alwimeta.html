1. Data yang Kami Kumpulkan

ALWI META adalah aplikasi portal keluarga yang berisi game offline (Heli, Mobil, Tank Ripuh, Stick Naga), halaman streaming, dan diskusi Al-Quran.

  • Tidak ada akun. Aplikasi tidak meminta login.
  • Tidak ada data pribadi (nama, email, nomor HP, lokasi) yang dikumpulkan otomatis.
  • Skor & XP game hanya disimpan di localStorage perangkat Anda sendiri.
  • Game offline berjalan penuh tanpa internet dan tanpa mengirim data apa pun.

2. Izin

Hanya izin akses internet (INTERNET) untuk membuka halaman streaming dan diskusi Al-Quran online. Tidak ada izin lain.

3. Data Pihak Ketiga

Halaman online (Streaming & Diskusi Al-Quran) disajikan dari layanan web keluarga. Kami tidak menjual dan tidak membagikan data Anda kepada pihak ketiga mana pun.

4. Penghapusan Data

Semua data game (skor & XP) berada di perangkat Anda. Hapus dengan:

  • Menu Setting di aplikasi (jika tersedia), atau
  • Buka pengaturan perangkat Android Anda > Aplikasi > ALWI META > Hapus Data, atau
  • Email kami di imahazzah51@gmail.com untuk bantuan.

Formulir penghapusan: https://indramayu-nur-ep1m.vercel.app/delete-alwimeta.html

5. Anak-anak

Aplikasi ini dirancang untuk seluruh keluarga termasuk anak-anak dan tidak mengumpulkan data pribadi dari siapa pun.

6. Perubahan Kebijakan

Kebijakan ini dapat diperbarui sewaktu-waktu. Perubahan akan diunggah di halaman ini.
